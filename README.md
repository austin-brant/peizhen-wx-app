# 陪诊预约小程序

为陪诊师打造的一站式预约与收款小程序。预约者可查看空闲时段、一次选择多个连续时段、填写信息、支付定金；服务结束后再次支付尾款。陪诊师可在管理端设置不可约时段、维护医院候选与备注选项、标记服务完成、按日/周/月/年统计订单与收入。

## 功能清单

| 角色 | 功能 |
|------|------|
| 预约者 | 微信授权登录（自动识别身份）、查看可约时段、整月日历弹窗快速切日期、一次选择多个连续时段（至少 2 小时）合并计费、医院候选下拉选择（可手写其他）、备注快捷选项、手机号一键微信授权获取、提交后等待陪诊师确认、在「我的」直接查看本人订单、一键联系陪诊师微信/电话 |
| 陪诊师 | 微信绑定管理员身份、首页可见管理入口、设置任意时段/整天不可约、编辑首页全部内容（服务名/陪诊师名/价格/公告/微信号/陪诊师头像等）、维护医院候选与备注选项、订单列表（按状态过滤）、确认预约/标记完成/取消/删除订单、日/周/月/年统计（按状态过滤） |

## 快速开始（本地联调）

### 1. 启动后端

要求：Node.js >= 16（本机已提供 Node 22）。

```bash
cd server
node server.js
```

启动后会监听 `http://127.0.0.1:8300`，并显示默认管理密码（初始为 `123456`）。

数据文件会自动创建在 `server/data/` 目录下。可选生成演示数据：

```bash
cd server
node seed-demo.js
```

### 2. 导入小程序

1. 打开 **微信开发者工具**
2. 选择「导入项目」
3. 选择本目录 `/Users/bytedance/WorkBuddy/wx-app`
4. 导入时 AppID 可先使用测试号，或填写你的小程序 AppID
5. 进入「详情 → 本地设置」，勾选：
   - ✅ 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书

### 3. 配置后端地址

打开 `miniprogram/app.js`，确认：

```js
baseUrl: 'http://127.0.0.1:8300'
```

开发者工具中默认即可访问本机后端。真机预览时需要改为 https 域名。

### 4. 微信登录（两种模式）

小程序 `app.js` 启动时静默调用 `wx.login` 换取 code 并上报后端。后端两种模式：

- **模拟模式（默认，本地联调用）**：无需 AppID/Secret，按 `code` 派生出稳定的 `dev_openid`。每次启动小程序 code 会变，因此**同一设备同一会话是同一个用户**，开发者工具中重新编译会换一个新身份。
- **真实模式（上线用）**：在管理端「设置」页填入 `wxaAppid` 与 `wxaSecret`（或设置环境变量 `WX_APPID` / `WX_SECRET`），后端调用 `jscode2session` 换取真实 `openid`，同一微信用户永久稳定。

### 5. 运行与测试

- 在「预约」Tab 选择日期 → 点选时段（支持连续多点选，可左右扩展、收缩端点）→ 底部显示「共 N 段」合并计费 → 填写信息 → 支付定金（模拟弹窗）→ 查看订单
- 点击日期栏右侧月份按钮，弹出整月日历，可切换月份并点击任意一天快速跳转（绿点=有可约时段，红点=约满/不可约）
- 首页顶部「联系我」按钮：已配置 `kfUrl`（企业微信客服链接）时直接拉起客服会话，否则复制微信号；电话按钮直接拨号
- 在「我的」Tab：微信授权后自动展示**本人的**预约记录，无需手输手机号
- 首页顶部内容（服务名/陪诊师名/价格/定金/公告/预约须知）均可由管理端编辑保存
- **管理入口仅对管理员可见**：用管理员微信在管理登录页完成「密码登录」（自动绑定当前微信），之后首页即显示「管理入口」，并可一键微信登录
- 管理端「设置」中可修改工作时间段、每段时长、价格、定金、微信号/客服链接，维护**就诊医院候选**与**备注快捷选项**，保存后立即生效
- 管理端「时间管理」可逐时段开关不可约状态
- 在「统计」页切换今日/本周/本月/本年查看订单数、时长、金额

## 管理员绑定说明（重要）

1. 打开小程序 → 首页**连续点击服务名称 5 次** → 进入管理登录页
2. 输入密码（初始 `123456`）登录 → 当前微信自动绑定为管理员
3. 之后同一微信进入管理登录页会出现「一键进入」按钮；首页也会自动显示「管理入口」
4. 管理员身份以 `adminOpenids` 列表保存在 `server/data/config.json` 中（服务端已启动时请勿直接改文件，用管理端页面操作）

## 支付说明（重要）

当前使用**模拟支付**模式：前端弹窗确认即视为支付成功，便于完整体验业务流程。

真实上线接入微信支付（JSAPI）的步骤：

1. 小程序账号完成认证，并开通「微信支付」，绑定商户号。
2. 后端新增统一下单接口，调用微信支付 API 生成 `timeStamp / nonceStr / package / signType / paySign`。
3. 将 `miniprogram/utils/pay.js` 中的 `wx.showModal` 替换为：
   ```js
   wx.requestPayment({
     timeStamp: payParams.timeStamp,
     nonceStr: payParams.nonceStr,
     package: payParams.package,
     signType: payParams.signType,
     paySign: payParams.paySign,
     success() { resolve(true); },
     fail() { resolve(false); }
   });
   ```
4. 微信支付回调通知商户后台后，调用服务端已有的「确认支付」逻辑（参考 `server.js` 中 `payDeposit` / `payTail`）。

后端 `/api/orders/:id/pay-deposit` 与 `/api/orders/:id/pay-tail` 已准备就绪，可直接作为支付回调的处理函数。

## 部署上线

### 后端部署

1. 将 `server/` 部署到云服务器（CentOS/Ubuntu/Debian）。
2. 配置 Nginx 反向代理到 `http://127.0.0.1:8300`。
3. 申请并配置 SSL 证书，使域名支持 HTTPS（小程序仅支持 https）。
4. 将 `miniprogram/app.js` 中的 `baseUrl` 改为你的 https 域名。

### 小程序后台配置

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → 开发 → 开发管理 → 开发设置。
2. 在「服务器域名」→「request 合法域名」中添加你的 https 域名。
3. 在「开发 → 开发管理 → 开发设置」中查看 AppID 与 AppSecret，填入管理端「设置」页（或环境变量），开启真实微信登录。
4. 提交审核并发布。

### 数据持久化建议

当前使用 JSON 文件存储，适合单人/初期业务。订单量增长后，建议将 `server/db.js` 替换为 SQLite / MySQL / CloudBase 等数据库，业务逻辑无需改动。

## 安全与隐私说明

- 用户以微信 `openid` 作为唯一身份标识；管理端通过密码登录后下发 token，token 24 小时有效。
- 上线前务必在「管理端 → 设置」中修改默认密码。
- `adminOpenids` 由首次密码登录自动绑定，防止他人冒充管理员。
- 订单状态变更（完成/取消）目前由管理端直接操作，真实业务可结合短信或微信订阅消息通知客户。

## 订单状态与确认流程

- 订单状态：**待确认（pending）→ 已确认（confirmed）→ 已完成（completed）**，任一状态可**取消（cancelled）**。
- 预约者提交后订单为「待确认」，陪诊师在管理端点击「确认预约」后订单才生效；确认时间记录在 `confirmedAt`。
- 预约时长**至少 2 小时**（需连选两个及以上时段），后端与前端双重校验。
- 陪诊师可在管理端**永久删除**订单记录（不可恢复）。

## 统计口径

- **订单数**：本周期内非取消状态的预约单数（默认排除 cancelled，含待确认/已确认/已完成；管理端可按状态单独过滤）。
- **服务时长**：非取消订单的时段总时长（小时）。
- **订单金额**：非取消订单的服务费总价（¥），按「每小时单价 × 时长 × 折扣率」计算。

统计周期按服务日期（订单中的 `date` 字段）划分，周一为每周开始。

## 常见问题

**Q：微信开发者工具提示「不在以下 request 合法域名列表中」？**  
A：在「详情 → 本地设置」勾选「不校验合法域名」。真机体验需配置 https 域名。

**Q：模拟模式下为什么每次重新编译「我的」页看不到之前订单？**  
A：模拟模式按登录 code 派生 openid，重新编译后 code 变化等于换了新用户。真机/上线使用真实 AppID 后 openid 永久稳定。

**Q：如何开启真实微信登录？**  
A：管理端「设置」页填入小程序 AppID 与 AppSecret 保存即可；或部署时设置环境变量 `WX_APPID` / `WX_SECRET`。留空即为模拟模式。

**Q：首页内容、价格、定金怎么改？**  
A：管理端 → 设置中可实时修改服务名、陪诊师名、价格、定金方式（固定/比例）、工作时间段、每段时长、公告、微信号、客服链接、医院候选、备注选项等，保存后立即生效。

**Q：找不到管理入口？**  
A：管理入口仅对已绑定管理员微信显示。未登录时在首页连续点击服务名称 5 次进入管理登录页，密码登录即自动绑定当前微信。

**Q：如何清空演示数据重新开始？**  
A：停止后端，删除 `server/data/` 目录，重新启动 `server.js` 即可。
